# Clastle

Inter-school social platform for clubs, events and student collaboration.

## Requirements

- Docker
- Docker Compose
- Node.js (for development)

## Installation

You can install and run Clastle using the provided `install.sh` script.

```bash
# Clone the repository
git clone https://github.com/MegeKaplan/clastle.git

# Navigate to the project directory
cd clastle

# Make the installation script executable
chmod +x install.sh

# Run the installation script
./install.sh
```
